The Case of the Exiled Letters: Why Latvian Banished Three of Its Own

Open a Latvian book today and you will see a calm, perfect lineup of 33 letters. It was not always so. That tidy row is the winner of a real battle: for centuries the alphabet was a messy field where borrowed scripts, German habits and obsolete sounds fought for space. Every alphabet has its outlaws, and Latvian keeps its exiles locked in a secret archive. Today we open the case file -- the investigation of the banished letters.

First, the setup. Latvian once tried to wear Gothic script, the ornate blackletter style, and it fit like clothes from someone else's shoulder -- a torment for a language it was never designed for. Then came the great reform of 1908, when linguist-heroes like Mīlenbahs and Endzelīns brought order to the alphabetical chaos and built what the episode calls the ideal code: one letter, one sound, no leftovers. Almost. Because three artifacts of the past had to be dealt with, and each got its own case file.

Case number one: the soft letter Ŗ. It was the tamed beast of the alphabet -- a rare, softened R-sound that almost nobody's tongue used anymore. A letter is only worth its slot if speakers reach for it, and speakers simply stopped. So Ŗ was gently exiled: the story of the disappearance of the rarest sound in the language.

Case number two: the long letter Ō. This one was not rare -- it was redundant. Latvian already had a way to write the long o-sound, so keeping Ō around was like a phone that still has a rotary dial bolted next to the touchscreen. Pure code optimization: the system worked better with the duplicate removed.

Case number three: the digraph CH. A digraph is two letters pretending to be one, and this particular pair was the last artifact of the German trace on the language. Once the ideal code had native single letters for that sound, the German-imported CH became a leftover from a former landlord's furniture. It was the final piece the language cleansed away.

Here is the detective's conclusion: none of this was vandalism. A language is a living organism -- it prunes what stops working so the rest can grow. And if you think the exiles are gone forever, check your phone: every time someone types latvian names in plain translit, the ghosts of the old letters come back for a visit. FAQ

Why did Gothic script fail for Latvian?

It was clothes from someone else's shoulder: an ornate style designed for other languages, a torment to read and write for Latvian. The reformers replaced it with a script that actually fits the sounds.

What was the great reform of 1908?

The cleanup that brought order to alphabetical chaos. Linguist-heroes like Mīlenbahs and Endzelīns organized the ideal code: a strict system where each letter matches one sound, with no leftovers.

Why exactly were Ŗ, Ō and CH removed?

Each failed a different test: Ŗ was the rarest sound -- speakers stopped using it; Ō was a redundant duplicate of an existing long o; CH was a German digraph artifact that native letters had made unnecessary.

Do the exiled letters still matter today?

As ghosts, yes. In the digital translit era, people typing Latvian without diacritics recreate the old confusion -- which is why the alphabet's history is still alive in every smartphone.
