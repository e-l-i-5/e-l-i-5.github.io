FAQ

Why does the video call cloud AI "rented"?

Because you pay recurring subscription or API fees for access that someone else controls, and your prompts travel to that company's servers. A local model like Jan runs on your own hardware with zero fees — you own it the way you own an appliance, not the way you lease an apartment.

Do I need to know how to code to use Jan?

No. Jan swaps top open-source models — Llama, Mistral, Qwen, DeepSeek, Gemma — in seconds without coding or a terminal. The video emphasizes it is built for everyone, not just developers, which is why millions already use it.

What happens to my data when the model runs locally?

It stays home. The model runs entirely on your laptop, so your questions never leave the room — there is no cloud server to leak them. Smart local memory extends this: the AI's memory of you lives on your own disk, not in a company's cloud profile.
